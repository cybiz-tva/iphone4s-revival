# Progress checkpoint — 25 October 2026

This checkpoint records completed work and remaining limits. No new carrier-unlock exploit or custom unlocking firmware has been discovered, built or flashed.

## Working setup

- iPhone 4s / iPhone4,1, iOS 9.3.6 (13G37), modem 6.7.00.
- Carbon jailbreak previously succeeded; the user subsequently reported using Iocaste untether for consistency. This checkpoint does not claim an independently measured cold-boot/reboot test.
- Earlier App Store and iCloud sign-in succeeded after 4SGSAFix; see the existing account-repair guide.
- Onegram's icon and existing account were recovered. Its local-notification declaration and app-specific persistent background helper produced Home Screen and locked-screen notifications. The user explicitly confirmed delivery after 20 minutes. This is connection keepalive/local notification support, not genuine APNs push; overnight reliability and battery impact remain unmeasured.
- [Open App Store](08-open-app-store.md) now combines a curated catalog, two reviewed direct-IPA entries, installed-app launching, source management and Cydia repository package listings. The expanded UI showed 61 entries. Source and host/native test fixtures are included.
- Non-Apple GUI payloads relocated during the work use the data partition. Cydia package handoffs can use system space and are not covered by that guarantee.

## App/service limits

Legacy MT5 displayed an outdated-client warning immediately at launch. No broker login/trading compatibility fix was demonstrated. Suppressing a version warning would not update its trading protocol. A working WhatsApp service on this iOS version was not established. Browser wrappers cannot be assumed to provide a modern underlying WebKit engine. These are unresolved limits, not completed repairs.

## SIM and carrier research

Latest read-only USB/network checks returned: ActivationState `Unactivated`, SIM `Ready`, Airtel carrier metadata, modem `6.7.00`, WCDMA radio indication and no cellular IPv4 interface. SIM readability and radio technology do not demonstrate network registration, calls, SMS or data.

Earlier SAM experiments corrected its legacy runtime loading and pseudo-SIM generation, then still received `SIM Not Supported` from activation. Exact-version analysis identified the proposed CommCenter hook as configuration-signature verification; a guarded live experiment did not observe a call to the selected function and achieved no unlock. Experimental changes were rolled back and original binaries/launch configuration/activation files matched backups. The retained Setup-screen bypass permits iOS access and is not a carrier unlock.

Fresh research found no verified software unlock for this exact modem configuration. [Legacy iOS Kit's developer documentation](https://github.com/LukeZGD/Legacy-iOS-Kit/wiki/Baseband-Update) distinguishes separate modem firmware and documents the absence of an ultrasn0w-style iPhone 4s unlock and unsigned modem-downgrade limitations. Custom IPSW packaging does not supply a missing modem exploit or accepted activation credential.

A [2019 user report](https://www.reddit.com/r/LegacyJailbreak/comments/diqaag/) described R-SIM use on iOS 9.3.6, but omitted the adapter revision, baseband and relevant carrier combination. [R-SIM's iOS 9 manual](https://www.rsim5.com/instructionview.php?id=63) does not establish Telstra-to-Airtel compatibility on 6.7.00. No adapter was physically tested or purchased. No recommendation of a specific guaranteed-compatible SKU is made.

The official Telstra request remained unanswered at the last user update. A follow-up draft was prepared, not sent. Cellular service remains unresolved. The [official unlock route](https://www.telstra.com.au/support/mobiles-devices/unlock-phone-imei) is documented without implying completion.

## Preserved privately / excluded

The private research repository holds the detailed continuation context and experimental results. Neither repository contains credentials, device identifiers, activation tickets, account sessions, raw device logs, backups, Apple firmware or third-party app binaries. The public store source contains developer URLs and hashes, not redistributed apps or the user's added-source cache.

Future work should preserve the working app/notification setup, distinguish hypotheses from demonstrated exploits, and verify actual calls/SMS/data before claiming cellular success.
